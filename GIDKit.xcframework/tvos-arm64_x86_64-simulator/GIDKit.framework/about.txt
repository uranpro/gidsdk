О компании.

ООО «Оператор Газпром ИД» (Основной вид деятельности: ОКВЭД 62.09) - это аккредитованная IT компания, специализирующаяся на разработках программных продуктов, направленных на создание и формирование цифровой платформы.
Основной наш продукт - программное обеспечение Газпром ID.
Газпром ID поможет сформировать единый профиль пользователя для всех партнерских сервисов.
Ключевая цель - это создание единой точки входа для всех ресурсов с единой авторизационной зоной.
Главные преимущества Газпром ID:
Для пользователя: вход по единому аккаунту во множество сервисов и персонализированные предложения.
Для бизнеса: готовое решение функционала авторизации и маркетинговый инструмент для привлечения и удержания пользователей.
